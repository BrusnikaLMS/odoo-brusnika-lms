Brusnika LMS for Odoo

Embed your LMS directly inside Odoo. Single Sign-On included.

What this addon does

Brusnika LMS is an enterprise learning management system by Brusnika.Solutions (Estonia-based company). This addon embeds the LMS directly inside Odoo -- no tab switching, no separate login required.

  • Embedded LMS -- opens as a native section in Odoo via the Learning menu
  • Single Sign-On (SSO) -- employees are logged in automatically via HMAC-signed URL
  • Employee sync -- reads hr.employee and hr.department from Odoo HR
  • Training notifications -- course events logged as mail.activity and chatter entries
  • Calendar sync -- LMS events can be synced with calendar.event

How SSO works

When an employee clicks Open LMS in the Odoo Learning menu, this addon generates a signed URL (HMAC-SHA256). Brusnika LMS validates the signature and logs the employee in automatically -- no credentials required on their end.

Setup

  1. Install this addon from apps.odoo.com
  2. Go to Learning > Settings in Odoo
  3. Enter your Brusnika LMS URL and the shared SSO secret
  4. In Brusnika LMS admin panel, configure the Odoo connection (URL, DB, API key)
  5. Done -- employees see the Learning menu with single-click LMS access

Requirements: Odoo 17.0 · Brusnika LMS subscription · public HTTPS on Odoo instance
